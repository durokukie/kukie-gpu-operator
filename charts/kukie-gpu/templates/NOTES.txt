{{- if .Values.rbac.enabled }}
- RoleBinding {{ .Values.rbac.clusterRole }} (그룹 {{ .Values.rbac.readerGroup }}): namespace {{ include "kukie-gpu.rbacNamespaces" . | fromJsonArray | join ", " }}
{{- end }}
{{- if .Values.demoVllm.enabled }}
- 데모 vLLM {{ .Values.demoVllm.name }} ({{ .Values.demoVllm.model }}): namespace {{ .Values.namespaces.llm }} (GPU 노드가 없으면 Pending)

{{- if .Values.preflight.enabled }}

{{- if .Values.oven.enabled }}
- 오퍼레이터 kukie-oven: namespace {{ .Release.Namespace }} (CRD servedmodels.serving.kukie.io는 uninstall해도 남습니다)

{{- if (.Values.counter | default dict).enabled }}

{{- end }}
